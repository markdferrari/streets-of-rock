# Observed defects resolved during implementation

- Final countdown could complete during an interrupt and never launch after safe Resume. A deterministic regression now proves exactly one launch after explicit safe resume, none while paused/unsafe.
- Runtime room imports initially lost the intended palette; explicit shared vertex-colour material remaps restore it. Native connectors/backing sample the imported palette to eliminate colour-space seams. Curtains and booth backing were moved in front of their walls; lettering/fixtures were fitted to the unchanged camera.
- Production validation/preparation previously covered only Grunt/Zoner. All rooms and roles, their skin bindings, actual clips, source/export hashes and supplier prop provenance are now required. Unknown roles cannot silently render primitive substitutes; wrong-kind scenes return actionable errors. Retry no longer trusts a cached template for a changed path.
- Reused actor IDs could inherit previous-run pose/defeat ownership. Run binding now clears all per-run character/projectile/object/effect state. Ten complete world cycles and browser retries settle owned imports.
- Imported limb motion lacked explicit charge/rope/shockwave footprints and phase-two styling. Per-instance cues now match existing simulation bounds, including the full 20-unit radial shockwave; a hand-bound rope line and nonblocking phase-two chevrons add the required reads.
- Original room captures exceeded the 100-call draw target. Room palette batching and compatible shared-material hero batching reduced checked Chromium room captures to 53–71 calls. Every triangle, hero material/skin resource and original hero source/runtime file remains unchanged. Complete phone performance is still pending.
- Adding persistent Credits controls exposed historical-order keyboard focus trapping. Focus now follows descriptor order and supports nested Settings/Credits return without resuming gameplay. The existing browser regression and new credit focus checks pass in both engines.
- A used supplier bottle was omitted from credit projection and full provenance validation. Both now include the inherited shipped props registry, with retained local acquisition/license evidence and the creator identity from its bundled license.
- The focused runner received empty reports from child Node/Bun invocations under this Bun build. It now explicitly pipes child stdout/stderr and invokes the installed Vitest entry with Node; empty reports still fail closed. The managed sandbox suppresses nested Node asynchronous output, so the verified actual scoped run uses normal execution and reports 62 GUT/22 Vitest passes.

Behavioral red/green cases and actual command outcomes are retained in [TDD](tdd.md) and `evidence/complete-art/`. No wave, health, damage, attack timing or camera budget was reduced to remedy these issues. The separately approved Grunt pursuit/throw-aim extension remains documented in the specification and parity fixtures.
